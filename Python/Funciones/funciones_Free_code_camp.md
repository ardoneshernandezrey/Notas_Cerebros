Argumentos, son simplemente valores que asig\
namos a un parametro cuando llamamos a una funcion
>>> 

Los argumentos son especificados en la llamada a la funcion.

luego los Argumentos son asignados a sus correspondientes parametros.

Vimos la comunicacion entre el programa principal y la funcion para pasar a recibir valores. Pero la funcion tambien puede retornar valores hacia el programa principal. El proposito de esta comunicacion es que la funcion retorne un valor al lugar donde fue llamada la funcion luego de completar la tarea.

Basicamente la diferencia entre RETURN Y PRINT, return nos retorna ese valor para poder trabajar con el, y print, simplemente lo muestra en la consola.
